# Viewer avatar artwork

Generated with the built-in `image_gen` tool, using the user's viewer-counter
screenshot as a style reference. The screenshot was not an edit target.

Production asset: `public/viewer-avatars.webp` (384 × 128, three equal square
portraits, 12,092 bytes). The generated sheet was resized and encoded as WebP
for the website; circular cropping is handled by CSS. No external avatar service
or real visitor photos are used.

## Generation prompt

Use case: stylized-concept. Asset type: one three-frame avatar spritesheet for a monochrome developer portfolio's anonymous live viewer counter. Create one WIDE 3:1 image consisting of THREE EQUAL SQUARE PANELS in a single horizontal row, no gutters or divider lines. In each square, center one DIFFERENT original adult manga character's head and upper shoulders, large close-up with generous 12% margin so a circular UI crop will show the entire head. LEFT: short dark swept-back hair, white collared shirt, dark tie, confident composed expression. MIDDLE: dark straight bob haircut with a side part, dark turtleneck, calm expression. RIGHT: wavy dark hair, round eyeglasses, light jacket, relaxed expression. These are anonymous illustrative avatar characters, not actual visitors or public figures. Match the small black-and-white anime portrait avatar treatment in the supplied screenshot reference: crisp black ink outlines, bold solid black hair shapes, clean ivory-white face highlights, restrained gray shading, readable even at 32px. All three have exactly matching scale and framing, heads centered at 1/6, 1/2, and 5/6 of the complete image width respectively. Every panel background is plain warm off-white #f5f4f0. No UI, no lettering, no labels, no numbers, no watermark, no circles or borders drawn into the image; the website supplies the circular masks. Reference screenshot is STYLE ONLY, not an edit target; ignore its text and UI.
